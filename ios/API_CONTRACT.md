# API Contracts -- QuickTrack Data Sources

> Each tracker's data source contract. Widget/adapter code consumes these.
> Supabase REST is auto-generated by PostgREST -- no custom endpoints needed.

---

## Common: Supabase REST Headers

All Supabase requests require:

```
Authorization: Bearer {jwt_token}
apikey: {anon_key}
Accept: application/json
```

For single-row responses (tables with `user_id` primary key):
```
Accept: application/vnd.pgrst.object+json
```

Base URL: `{SUPABASE_URL}/rest/v1`

## Tracker 1: Medication / Supplements

### Read: Today's Check Status

**Request**:
```
GET /rest/v1/daily_habits?select=daily_checks,time_blocks&user_id=eq.{userId}
Accept: application/vnd.pgrst.object+json
```

**Response** (200):
```json
{
  "daily_checks": {
    "2026-05-07": {
      "m_water": true,
      "m_dental": true,
      "m_supplements_morning": true,
      "a_zone2": true
    },
    "2026-05-06": { ... }
  },
  "time_blocks": [
    {
      "key": "morning",
      "icon": "sunrise",
      "time": "07:00-12:00",
      "activities": [
        { "id": "m_water", "icon": "droplet", "label": "Water" },
        { "id": "m_dental", "icon": "tooth", "label": "Dental" },
        { "id": "m_supplements_morning", "icon": "pill", "label": "Centrum+B+C, Creatine+LIV" },
        ...
      ]
    },
    {
      "key": "afternoon",
      "activities": [
        { "id": "a_supplements_lunch", "icon": "pill", "label": "Omega-3+Turmeric+Zinc" },
        ...
      ]
    },
    {
      "key": "evening",
      "activities": [
        { "id": "e_magnesium", "icon": "pill", "label": "Magnesium L-Threonate (21:30)" },
        ...
      ]
    }
  ]
}
```

**Transform to TrackerSummary**:
```
todayKey = "YYYY-MM-DD" (today)
todayChecks = daily_checks[todayKey] ?? {}
allActivities = time_blocks.flatMap { $0.activities }
checkedCount = allActivities.filter { todayChecks[$0.id] == true }.count
totalCount = allActivities.count

TrackerSummary(
  trackerId: "medication",
  currentValue: Double(checkedCount),
  label: "\(checkedCount)/\(totalCount) completed",
  subtitle: uncheckedItems.first?.label ?? "All done!",
  progress: Double(checkedCount) / Double(totalCount),
  trend: last7DaysCompletionRates,
  actionItems: uncheckedActivities.map { ActionItem(id: $0.id, label: $0.label, ...) }
)
```

**Null handling**: If `time_blocks` is null, use generic defaults:
```swift
let DEFAULT_ACTIVITIES = [
    ("morning", [("m_water", "Water"), ("m_exercise", "Exercise"), ("m_breakfast", "Breakfast")]),
    ("afternoon", [("a_walk", "Walk"), ("a_focus", "Focus block"), ("a_stretch", "Stretch")]),
    ("evening", [("e_dinner", "Dinner"), ("e_winddown", "Wind-down"), ("e_sleep", "Sleep on time")])
]
```

### Write: Check Off Activity (Phase 3)

**Request**:
```
PATCH /rest/v1/daily_habits?user_id=eq.{userId}
Content-Type: application/json

{
  "daily_checks": {
    ...existingChecks,
    "2026-05-07": {
      ...existingToday,
      "m_supplements_morning": true
    }
  }
}
```

**IMPORTANT**: This is a full-column replace (JSONB). Must read-modify-write:
1. GET current `daily_checks`
2. Merge new check into today's key
3. PATCH entire `daily_checks` column

**Alternative** (if Supabase supports jsonb_set):
```
PATCH with Prefer: return=representation
RPC call: select jsonb_set(daily_checks, '{2026-05-07,m_supplements_morning}', 'true')
```
Evaluate which approach is simpler during Phase 3 implementation.

## Tracker 2: QuestStar Progress

### Read: Game State

**Request**:
```
GET /rest/v1/game_state?select=xp,streak,last_active_date&user_id=eq.{userId}
Accept: application/vnd.pgrst.object+json
```

**Response** (200):
```json
{
  "xp": 1250,
  "streak": 5,
  "last_active_date": "2026-05-07"
}
```

### Read: Active Quests (next step)

**Request**:
```
GET /rest/v1/quests?select=id,name,steps,deadline,tag&user_id=eq.{userId}
```

**Response** (200):
```json
[
  {
    "id": "abc123",
    "name": "Learn React Hooks",
    "steps": [
      { "id": "s1", "text": "Read useState docs", "done": true, "difficulty": "easy" },
      { "id": "s2", "text": "Build counter example", "done": false, "difficulty": "medium" },
      { "id": "s3", "text": "Implement custom hook", "done": false, "difficulty": "hard" }
    ],
    "deadline": "2026-05-10",
    "tag": "Stage 3"
  },
  ...
]
```

**Transform to TrackerSummary**:
```swift
let level = LEVELS.last(where: { $0.threshold <= xp })
let nextLevel = LEVELS.first(where: { $0.threshold > xp })
let progress = nextLevel.map { Double(xp - level.threshold) / Double($0.threshold - level.threshold) }

// Find most urgent incomplete quest
let activeQuests = quests.filter { q in q.steps.contains { !$0.done } }
let urgentQuest = activeQuests
    .sorted { ($0.deadline ?? "9999") < ($1.deadline ?? "9999") }
    .first

let nextStep = urgentQuest?.steps.first { !$0.done }

// Streak warning
let isStreakAtRisk = lastActiveDate != todayString

TrackerSummary(
  trackerId: "queststar",
  currentValue: Double(xp),
  label: "Lv.\(level.index) \(level.name) | \(xp) XP",
  subtitle: isStreakAtRisk ? "Streak at risk! Do 1 step" : "Streak: \(streak) days",
  progress: progress,
  trend: nil,  // no historical XP data readily available
  actionItems: nextStep.map { [ActionItem(id: $0.id, label: $0.text, ...)] }
)
```

### Streak Risk Detection
```swift
// lastActiveDate is "YYYY-MM-DD" string
let today = DateFormatter.yyyyMMdd.string(from: Date())
let isActiveToday = lastActiveDate == today

// If not active today AND it's past 18:00, show warning
let hour = Calendar.current.component(.hour, from: Date())
let showWarning = !isActiveToday && hour >= 18
```

## Tracker 3: Sleep

### Read: HealthKit Sleep Analysis

**No HTTP API** -- uses HealthKit SDK directly.

```swift
import HealthKit

let healthStore = HKHealthStore()
let sleepType = HKCategoryType(.sleepAnalysis)

// Request authorization
func requestAuth() async throws {
    try await healthStore.requestAuthorization(toShare: [], read: [sleepType])
}

// Query last night's sleep
func fetchLastNightSleep() async throws -> TimeInterval {
    let now = Date()
    let startOfToday = Calendar.current.startOfDay(for: now)
    let startOfYesterday = Calendar.current.date(byAdding: .day, value: -1, to: startOfToday)!

    let predicate = HKQuery.predicateForSamples(
        withStart: startOfYesterday,
        end: now,
        options: .strictStartDate
    )

    let descriptor = HKSampleQueryDescriptor(
        predicates: [.categorySample(type: sleepType, predicate: predicate)],
        sortDescriptors: [SortDescriptor(\.startDate)]
    )

    let samples = try await descriptor.result(for: healthStore)

    // Filter for actual sleep (not "in bed")
    let sleepSamples = samples.filter { sample in
        let value = HKCategoryValueSleepAnalysis(rawValue: sample.value)
        return value == .asleepUnspecified || value == .asleepCore
            || value == .asleepDeep || value == .asleepREM
    }

    return sleepSamples.reduce(0) { $0 + $1.endDate.timeIntervalSince($1.startDate) }
}

}
```

## Error Responses

### Supabase Errors

| Status | Meaning | Widget Behavior |
|--------|---------|-----------------|
| 200 | Success | Show data |
| 401 | JWT expired / invalid | Show "Re-login required" with lock icon |
| 403 | RLS violation | Show "Access denied" (should not happen with correct user_id) |
| 404 | No row found | Show defaults / empty state |
| 500+ | Server error | Show cached data + "Last updated: {time}" |
| Network error | No connectivity | Show cached data + "Offline" indicator |

### HealthKit Errors

| Error | Widget Behavior |
|-------|-----------------|
| Not authorized | Show "Grant Health access in Settings" |
| No data available | Show "No sleep data" with dash |
| Source not available (macOS) | Show "Requires iPhone" on macOS |
