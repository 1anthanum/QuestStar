# /explain

用通俗中文解释 **$ARGUMENTS** 在做什么。假设读者完全不懂编程。

## 流程

### 若 $ARGUMENTS 是一个文件

1. 读这个文件
2. 读它所在目录的 `CLAUDE.md`（若存在）
3. 用中文输出：

```
## 这个文件做什么
[一段话日常语言描述]

## 它接收什么、产生什么
- 输入：…
- 输出：…

## 它依赖哪些其他文件
- …

## 哪些情况下需要修改它
- …

## 如果删掉它会发生什么
[一段话]
```

### 若 $ARGUMENTS 是一个目录

1. 读这个目录下所有源文件
2. 读这个目录的 `CLAUDE.md`（若存在）+ 父目录 CLAUDE.md
3. 用中文输出：

```
## 这个目录做什么
[一段话]

## 主要文件
- file_a.py：[一句话]
- file_b.py：[一句话]
…

## 这个目录与项目其他部分的关系
- 被谁调用：…
- 调用谁：…

## 如果接手维护这个目录，最值得先理解的三件事
1. …
2. …
3. …
```

## 约束

- 用日常中文，禁止技术行话
- 必须用术语时立刻用一句中文解释
- 不确定的地方写「不确定」
- 不要超过 300 字（具体内容不限，避免长篇大论）

## 完成后

询问用户：

> 这个解释清晰吗？需要更通俗 / 更详细 / 转换成语音朗读？
